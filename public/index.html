Windows Server 24/7 Background Service

To keep this monitor running across reboots and user logoffs, install it as a Windows background task using the provided script.

One-Click Persistence Installation:

Open PowerShell as Administrator in the application directory and run:

.\register-service.ps1            # or: .\register-service.ps1 -Port 5000
What register-service.ps1 does:
• Automatic boot startup before any user logs in.
• Auto-recovery: restarts within 1 minute if it stops.
• Firewall rule for the dashboard/webhook port.
Note: Windows toast notifications are not visible when running as a background service. Use email, Telegram, WhatsApp or Teams for 24/7 alerting.
